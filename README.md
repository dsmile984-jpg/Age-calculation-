# Age-calculation-
Ek complete 5-page Age Calculator web app — DOB se exact age (saal-mahine-din) nikalta hai, 100 logo tak ki age aapas mein compare karta hai, photo (gallery/camera/URL) ke saath details upload karke gallery mein dikhata hai, aur sab kuch profile page par save rehta hai. Simple, mobile-friendly, dark theme design ke saath.
